# Toll fee calculator 1.0
A calculator for vehicle toll fees.

## Instructions
Make sure the dotnet 8 SDK is installed.

Run `dotnet build` from the C# directory followed by `dotnet run` to start the aplplication. Run `dotnet test` to execute the unit tests.
